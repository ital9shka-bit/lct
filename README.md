# СтройКонтроль

Демонстрационный сервис для контроля строительства по фотографиям камер. Он сопоставляет результаты AI-анализа с планом работ и показывает объяснение дневной оценки.

**Демо:** [pavelpetrov.tech](https://pavelpetrov.tech) · вход `demo/demo`

**Презентация:** [PowerPoint](presentation/СтройКонтроль_ЛЦТ2026.pptx) · [PDF для просмотра](presentation/СтройКонтроль_ЛЦТ2026.pdf)

## Что можно показать

- Загрузку фотографий с нескольких камер и их анализ через GateLLM.
- Сохранённые кадры, ответы модели и историю проверок двух объектов.
- Признаки работ по этапам, возможное отклонение и сигнал об отсутствии видимых перемещений техники за несколько дней.

Вывод по фотографии требует проверки человеком: камера видит только часть площадки и отдельные моменты времени.

## Модель данных

В PostgreSQL хранятся пользователи, объекты, камеры, план работ, проверки, ответы AI и рассчитанные оценки. Исходные фотографии хранятся в S3; база содержит ключи файлов и метаданные.

[Полная модель данных и ER-диаграмма](docs/DATA_MODEL.md) описывают 15 таблиц, их связи и правила сохранения результатов.

## Запуск

Потребуются Docker и Docker Compose. Создайте `.env` по `.env.example`, укажите ключ GateLLM в `AI_API_KEY`, затем выполните:

```bash
docker compose up -d --build
docker compose exec backend python -m backend.app.cli seed-demo
```

Сайт откроется на `http://127.0.0.1:8180`. Команда заполнения и загрузка новых фото используют настоящий AI-анализ. Для запуска на сервере есть `compose.prod.yaml` и `.env.prod.example`; рабочие ключи в репозиторий не входят.
