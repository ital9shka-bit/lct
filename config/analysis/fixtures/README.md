# Fixtures анализа

`synthetic-valid.response.json` — вручную подготовленный пример только для тестов схемы. Он не является ответом модели и не может показываться как живой анализ.

`live/gatellm-luna-w0-v1.response.json` — нормализованный ответ реального запроса GateLLM от 19 сентября 2026 года. Рядом сохранены метрики. Исходный ответ, request id и манифест запроса находятся в `artifacts/w0-runs/20260919T123520Z/`.

Новые живые фикстуры создаются только успешным запуском `scripts/run_w0_analysis.py --promote-fixture <name>` после прохождения схемы и семантической валидации.
